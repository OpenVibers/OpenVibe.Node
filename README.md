# OpenVibe Node

One service for your computers, servers, Raspberry Pis, phones and robots: pair it once with OpenVibe and products like OpenVibe.Bot (robots) and OpenVibe.Actor (AI agents) can use the device safely. It connects out, needs no open ports, and keeps a local kill switch.

Status: being built. Start here: [docs/HANDOFF.md](docs/HANDOFF.md) and [docs/ADR-043-bot-devices-and-control.md](docs/ADR-043-bot-devices-and-control.md).
